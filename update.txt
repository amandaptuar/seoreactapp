100% DYNAMIC DATA INTEGRATION (NO STATIC / MOCK DATA):
------------------------------------------------------
Pehle humne dynamic look dene ke liye mock/fake data generate kiya tha. 
Ab humne use poori tarah se hata diya hai. Ab poora data 100% user ke 
actual input par chalega aur directly engagement model (`/api/v1/summary` 
aur `/api/v1/roadmap`) se dynamically calculate hoga.

Iske liye humne user-facing dashboard par do main interactives add kiye hain:

1. 🌡️ INLINE WELLNESS LOGGING:
   - "Daily Wellness" card par agar user ne aaj check-in nahi kiya hai, 
     toh wahan ek dynamic "Log Daily Wellness" button dikhega.
   - Button click karte hi inline sliders (Sleep, Stress, Energy, Focus) 
     aur note field khul jayenge.
   - Save karne par yeh data user ki `localStorage` mein date ke sath save 
     hoga aur automatically summary update hogi.
   - Agar aaj ka check-in ho chuka hai, toh "✓ Logged today" status aur 
     emoji rating dikhegi.

2. 🗺️ TASK COMPLETION TOGGLE:
   - Roadmap weeks ke andar jitne bhi tasks hain, unpar ab user click 
     karke aaj ke liye completion status toggle kar sakta hai.
   - Task completed hone par:
     • Task text par strike-through (line-through) aayega aur opacity 70% 
       ho jayegi.
     • Ring icon green checkmark (✓) ban jayega.
     • Task ke neche badge dikhega: (e.g. "3 completed") — jo show karega 
       ki yeh task user ne ab tak kitni baar complete kiya hai.
   - Click karte hi completion data update hota hai aur summary re-fetch 
     hoti hai.

3. 🔄 RESET BUTTON:
   - Agar user apni checking ya completion history clear karke fir se zero 
     se start karna chahta hai, toh section ke sabse neeche right corner pe 
     "Reset Daily Check-ins & Completions" button diya gaya hai.


DASHBOARD METRICS (SUMMARY STATE MAPPING):
------------------------------------------

- Day Streak 🔥: Actual consecutive check-in streak.
- Week / Overall Adherence: Dynamic calculations based on expected tasks 
  vs completions from the model.
- Wellness Trends: Sleep, Stress, Energy, Focus rollings automatically 
  calculated by the model from check-ins logged (minimum number of check-ins 
  are required for trends, model dynamic output is shown directly).
- Behind This Week: Displays tasks that expected completions but have 
  underperformed based on active local dates.
